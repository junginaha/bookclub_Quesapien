# 한국어 폰트

PDF 생성을 위해 다음 폰트 파일을 이 디렉토리에 배치하세요:

- NotoSerifKR-Regular.ttf
- NotoSerifKR-Bold.ttf  
- NotoSansKR-Regular.ttf
- NotoSansKR-Bold.ttf

## 다운로드

Google Fonts에서 다운로드:
- https://fonts.google.com/noto/specimen/Noto+Serif+KR
- https://fonts.google.com/noto/specimen/Noto+Sans+KR

또는 setup.sh 실행:
```bash
bash backend/setup_fonts.sh
```
